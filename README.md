# Lab-Exercise-4
To design a simple wireframe diagram for a generic application or website using Balsamiq, including Welcome, Login/Signup, Home/Dashboard, Product Listing, and Checkout/Final Action screens.

ALGORITHM :
Open Balsamiq and create a new wireframe project.
Create the Welcome/Splash Screen with a logo and welcome message.
Create the Login/Signup Screen with username/email, password, and login/signup buttons.
Create the Home/Dashboard Screen with a search bar, categories, and navigation options.
Create the Product Listing Screen with product details, search, filter, and add-to-cart options.
Create the Checkout/Final Action Screen with order details, payment information, and a final action button.
Connect the screens to show the navigation flow between them.
Save the completed wireframe.
